## 开始安装
双击安装包进行安装流程，择自定义安装, 因为有些应用我们可能用不到
![installer](/code/database/mysql/custominstall.png)
选择要安装的服务, 并点击箭头 将其添加到右边
![installer](/code/database/mysql/jiantou.png)
选中右边的选项，可以发现一个小按钮（很小不想让我们改路径），建议将C改成D即可
![installer](/code/database/mysql/setpwd.png)
![installer](/code/database/mysql/changpwd.png)
点击execute安装即可
![installer](/code/database/mysql/anzhuang.png)
execute完成后，点击next下一步
![installer](/code/database/mysql/next.png)
![installer](/code/database/mysql/next2.png)
mysql配置页面默认配置不用改
![installer](/code/database/mysql/default.png)
使用mysql推荐的强策略。如果后面我们要用到数据库图形化工具的话(navicat举例)，如果navicat版本太老, 比如11, 会产生数据库连接错误，就建议选择第二个密码选项 或者升级软件图形化工具的版本。
![installer](/code/database/mysql/strong.png)
设置mysql的密码
![installer](/code/database/mysql/setpassword.png)
这里可以改成MySQL, 在启动服务的时候方便些
![installer](/code/database/mysql/qidong.png)
